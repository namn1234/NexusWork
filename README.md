# NexusWork

A full-stack MERN Job Portal project.

## Tech Stack
- Frontend: Next.js / React
- Backend: Node.js, Express
- Database: MongoDB

## Features
- User authentication
- Job posting
- Job applications
- Company management

## How to run

### Backend
cd nexuswork-backend
npm install
npm start

### Frontend
cd nexuswork
npm install
npm run dev

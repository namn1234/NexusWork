# 🧑‍💼 NexusWork

A full-stack MERN job portal that connects employers and job seekers through role-based dashboards, job listings, authentication, and application management.

🌐 **Live Demo:** https://nexus-work-pi.vercel.app  
🐙 **Repository:** https://github.com/namn1234/NexusWork

---

## 🚀 Features

### For Candidates
- 🔍 Browse available jobs
- 📝 Apply to job listings
- 📊 Track applications
- 🔐 Secure authentication

### For Recruiters
- ➕ Create job listings
- 🗂️ Manage posted jobs
- 👥 Review applicants
- 📊 Role-based dashboard

### Platform
- 🔑 JWT authentication
- 👤 Role-based access control
- 🌐 REST API architecture
- ☁️ Cloud database
- 📱 Responsive React UI

---

## 💻 Run Locally

```bash
git clone https://github.com/namn1234/NexusWork.git
cd NexusWork
npm install
```

Configure environment variables for MongoDB and JWT, then run the frontend and backend development servers.

---

## 🎯 Purpose

NexusWork demonstrates full-stack MERN development, authentication, role-based authorization, database integration, REST APIs, and production deployment.
